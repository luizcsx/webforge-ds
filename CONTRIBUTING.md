# Contributing to WebForge DS

Thank you for your interest in WebForge DS! To maintain a focused, organized, and efficient development workflow, all community contributions, theme submissions, and discussions are managed exclusively through our official channels.

 Please note that the GitHub Issues tracker for this repository is disabled. Do not look for it to report bugs or submit feature requests.

## How to Contribute

### 1. Join the Discussion
All communication regarding the development of WebForge DS, including bug reports, feedback, and project brainstorming, takes place on our **Official Discord Server**. 
* If you find a bug or have a suggestion, please join the server and post it in the designated channels.

### 2. Theme Packs & Visual Customization
WebForge DS supports custom themes made by the community using our styling syntax. 
* To share your custom theme packs, submit them in the appropriate Discord channel. 
* Approved community themes may be officially packaged into future releases of the system.

### 3. Code Contributions (Pull Requests)
If you wish to contribute directly to the C++ codebase or improve the core syntax interpreters (`.PER`, `.STY`, `.DSJS`):
1. **Discuss First:** Before writing any code, pitch your idea or discuss the fix in the developer channels on our Discord to ensure it aligns with the project's architecture and roadmap.
2. **Fork & Branch:** Fork the repository and create your feature branch directly through the GitHub interface or your preferred setup.
3. **Submit a PR:** Open a Pull Request pointing to our `main` branch with a clear description of the changes.

## Code Style & Standards

* **Keep it Bare-Metal Friendly:** Remember that the Nintendo DS has strict hardware limitations (67 MHz ARM9 CPU and 4 MB of RAM). Code efficiency, tight memory management, and optimized loops are mandatory.
* **Clean Syntax:** Keep the custom parser logic modular and easy to maintain.
* **Documentation:** If your code introduces new behavior or changes existing protocol standards (`wscs://`), ensure the core specifications are updated accordingly.

*Note: This project is driven by a focused and serious development approach. We appreciate your respect for our workflow and community guidelines.*
